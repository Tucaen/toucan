# Brain-dump library UI

Ideas captured by the brain-dump skill need a visible home in ADE so users can review what the skill organized after the conversation moves on.

## Current understanding

- The skill persists polished topic files, but the user currently has no dedicated interface for seeing that output.
- ADE should provide a UI where users can browse and read all of the ideas they have dumped.
- The experience should expose the organized topic archive rather than requiring users to inspect repository files manually.
- An idea should be assignable to a concrete ADE project when that project already exists; ideas that do not yet belong to an existing project must remain valid and browsable.

## Open questions

- Where should the idea library live in ADE's navigation?
- Should users only browse topics, or also search, edit, link, archive, and promote them into planned work?
- How should the UI indicate when a new dump created a topic versus updated an existing one?
- Can one idea belong to more than one project, and how should unassigned ideas be presented?
